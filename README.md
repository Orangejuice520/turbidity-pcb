## 📐 PCB 布局说明

- **板子尺寸**: 60mm × 50mm（小巧，适合野外部署）
- **层数**: 双层（F.Cu + B.Cu）
- **板厚**: 1.6mm
- **铜厚**: 1oz
- **GND**: 正反面铺铜

## 🚀 导入嘉立创 EDA 的方法

### 方法一：直接导入 KiCad 文件（推荐）

1. 打开 **嘉立创EDA专业版**: https://pro.lceda.cn
2. 点击 **文件 → 导入 → KiCad**
3. 选择 `turbidity_pcb` 文件夹中的 `.kicad_sch` 和 `.kicad_pcb` 文件
4. 导入后会看到原理图和PCB布局

### 方法二：手动在嘉立创 EDA 中重建

如果导入有问题，可以按下面的接线表手动画：

## ⚠️ 注意事项

1. **导入后务必检查网络连接** — 嘉立创导入KiCad文件时，部分连线可能需要手动修正
2. **检查元件封装** — 确认0805电阻/电容、DIP-8、SOT-23封装正确
3. **铺铜设置** — 正反面GND铺铜，间距0.5mm
4. **线宽** — 信号线0.25mm，电源线0.5mm
5. **打板参数** — 参照文档中的设置：板厚1.6mm，铜厚1oz，绿色
